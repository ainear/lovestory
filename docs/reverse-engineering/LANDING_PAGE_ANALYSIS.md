## Visual Design Analysis

### Color Scheme
- **Background:** Dark navy/black (#0D1117 range)
- **Primary Accent:** Coral/Pink (#FF4785)
- **Cards:** Dark grey with subtle borders (#1A1D23)
- **Text:** White (headings), Light grey (body)
- **Gradient:** Blue-to-pink subtle gradients on section backgrounds

### Typography
- **Logo:** Custom cursive/script font "Cinelove"
- **Headings:** Modern sans-serif (likely Inter or similar)
- **Body:** Clean sans-serif, good line-height for readability
- **Vietnamese:** Full diacritics support

### Interactive Elements
- Floating customer service button (bottom-right, coral)
- Hover effects on template cards (reveal eye/heart icons)
- Smooth scroll animations
- Responsive mobile navigation (hamburger menu)

---

## Key Observations
1. **Mobile-first design** — All templates optimized for phone viewing
2. **Dark theme** conveys premium positioning
3. **Social proof** is prominent (real customer invitations section)
4. **Conversion-focused** — CTA buttons on every section
5. **Multi-channel support** — Messenger, Zalo chat widgets
